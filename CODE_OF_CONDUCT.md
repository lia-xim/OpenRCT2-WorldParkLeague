# Code of Conduct

## Our standard

We want this project to be welcoming, curious, respectful, and constructive.

Examples of positive behavior:

- assuming good intent
- giving clear and respectful feedback
- explaining disagreement without hostility
- helping newer contributors learn the project
- focusing on the work instead of the person

Examples of unacceptable behavior:

- harassment or personal attacks
- insulting, belittling, or hostile language
- repeated bad-faith engagement
- publishing private information without permission
- deliberately disruptive behavior

## Scope

This applies to GitHub issues, pull requests, discussions, release comments, and other project spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, or contributions that do not align with this Code of Conduct.

## Reporting

If something needs moderator attention, open a private security-style report using the guidance in [SECURITY.md](./SECURITY.md) or contact the maintainer directly through GitHub.
